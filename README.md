# 🌌 Super Mario Galaxy Landing Page

Uma landing page inspirada no universo de **Super Mario Galaxy**, desenvolvida com foco em:
- experiência visual imersiva
- animações modernas
- responsividade
- performance
- organização profissional de código

O projeto apresenta personagens, trailers, efeitos espaciais e seções interativas inspiradas no jogo da Nintendo.

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Canvas API
- Intersection Observer API
- Responsive Design
- Flexbox
- CSS Animations
- Web Performance Optimization

---

- Renderização dinâmica de estrelas

- Navegação flutuante
- Scroll suave entre seções
